# Security

BW Lite handles vault keys and passwords, so security reports are welcome and taken seriously.

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/yowmamasita/bw-lite/security/advisories/new). Please don't open a public issue for it. Include the version (from `manifest.json` or the store page), the browser, and steps to reproduce.

You'll get a reply within a week. Fixes ship as a new version in both stores, and the advisory is published once the fix is out.

Only the latest release is supported. Problems in Bitwarden or Vaultwarden themselves belong with those projects.
